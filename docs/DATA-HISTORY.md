# Durable readings and limitations

Heating: background task starts 20 seconds after app readiness, shares the existing read-only myUplink adapter/cache, runs every 15 minutes, no writes to the heat pump. `/data/heating-history` (derived from configured token-file parent) contains private atomic JSON records. Source timestamp, fetch time and recording time remain separate. Repeated values/source times are deduplicated across restart. 30-day retention, 64 MiB archive cap, minimum64 MiB free disk, no secrets in records. Old source timestamps may represent last change; they do not by themselves prove a broken source. Selected enum labels now override misleading physical units in UI. Raw values are retained. Status endpoint `/api/heating/history/status` requires existing login.

Motion: hooks existing successful Homey inventory reads, does not create new integration polling. Captures Boolean alarm_motion and alarm_presence (including suffix variants), all device IDs except Tesla. Initial states are labelled initial observations, transitions retain source and observed times. No exact event-stream guarantee; short events between polls can be lost. Duplicate/older reports ignored. Persistent existing config namespace, bounded to7days/2000records; no upstream automations, locks, cameras or microphone calls. Site affiliation is unknown pending verified mapping; room from Homey zone. App log cannot retroactively reconstruct history. Storage errors do not block device reads. Durable config must be on existing volume.

Prices: https://www.hvakosterstrommen.no/strompris-api (checked2026-10-17) explicitly allows free use with no key, historical coverage since2021-12-01, ex-VAT prices, tomorrow no earlier than13:00. Source converts ENTSO-E EUR using Norges Bank and may differ from Nord Pool NOK. No numerical source rate limit published on checked page. Conservative job: max3requests/hour, today/tomorrow/rotating prior7days, 404 unavailable not zero,429Retry-After plus exponential backoff. Never forecasts; never fabricate publication timestamp (null); firstObservedAt and fetchedAt separate. Preserves actual15/60minute intervals, DST, negative prices, holes and immutable price revisions. Retention730days/64MiB/free-diskguard64MiB. No VAT/grid fees/taxes/subsidies added. Full historical backfill not enabled.
